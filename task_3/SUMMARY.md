# Задание 3: Создание векторного индекса базы знаний

## Результат выполнения

### 1. Модель эмбеддингов

- **Название:** `sentence-transformers/multi-qa-mpnet-base-dot-v1`
- **Репозиторий:** https://huggingface.co/sentence-transformers/multi-qa-mpnet-base-dot-v1
- **Размер эмбеддингов:** 768 измерений
- **Специализация:** Question-Answering
- **Distance metric:** Cosine
- **Ускорение:** MPS (Apple Silicon)

### 2. База знаний

- **Источник:** 70 документов из фэнтезийной вселенной с автоматически сгенерированными фэнтезийными именами
- **Чанкинг:** 600 символов, overlap 200, RecursiveCharacterTextSplitter (LangChain)
- **Title-boosting:** Имя документа добавляется в начало каждого чанка для улучшения поиска по именам

### 3. Векторный индекс

- **БД:** ChromaDB v0.4.22 (embedded mode)
- **Чанков:** 616
- **Размер на диске:** ~8 MB
- **Время генерации:** 24.82 секунды
- **Файл:** `task_3/chroma_db/`

### 4. Оптимизация

**Протестировано:** 12 конфигураций (3 модели × 4 параметра чанкинга)  
**Тестовых запросов:** 30

**Выбрана:** multi-qa-mpnet-base-dot-v1 + chunk_size=600, overlap=200

**Метрики на тестовой выборке:**

- Recall@1: 50.0% (лучший результат среди всех конфигураций)
- Recall@3: 53.3%
- Average similarity: 0.715 (лучший результат среди всех конфигураций)

**Улучшения:**

- ✅ Title-boosting улучшил поиск по именам (similarity 0.6 → 0.8)
- ✅ MPS acceleration ускорил индексацию в 3× (70s → 24s)
- ✅ Cosine similarity дает корректные значения [0, 1]

### 5. Код создания индекса

**Скрипт:** `task_3/build_index.py`

**Установка и запуск:**
