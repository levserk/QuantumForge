# Задание 2: Подготовка базы знаний

## Что делает

Собирает статьи с сайта, очищает их, заменяет все названия/имена на вымышленные фэнтезийные и готовит базу знаний для RAG-бота.

## Как запустить (пошагово)

### 1. Установка зависимостей

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Сбор ссылок

```bash
python scripts/1_crawl_links.py
```

**Результат:** `links.txt` — список URL статей для скачивания (50+)

### 3. Скачивание HTML

```bash
python scripts/2_download_pages.py
```

**Результат:** `raw_html/` — HTML-файлы статей

### 4. Очистка HTML → текст

```bash
python scripts/3_clean_html.py
```

**Результат:** `cleaned_texts/` — чистые текстовые файлы (~70 шт)

### 5. Генерация словаря замен

```bash
python scripts/4_generate_fantasy_terms.py
```

**Результат:** `terms_map.json` — словарь оригинал → фэнтезийное имя (~2400 замен)

**Примеры:**

- "Единое Кольцо" → "Рыин Кэен"
- "Нуменор" → "Нимеен"
- "эльфы" → "хехы"
- "гномы" → "гызы"

### 6. Замена терминов в текстах

```bash
python scripts/5_replace_terms.py
```

**Результат:** `knowledge_base/` — тексты с заменёнными именами + переименованные файлы

### 7. Финальная чистка

```bash
python scripts/6_cleanup_english.py
```

**Результат:** `knowledge_base/` — удалены все английские названия, диакритика, упоминания оригинального источника

## Итог

📁 **`knowledge_base/`** — готовая база знаний (70 документов) для создания векторного индекса (Задание 3)

## Ключевые особенности

1. **Составные термины сохраняются:** "Единое Кольцо" → "Рыин Кэен" (не просто "Прокл")
2. **Морфология работает:** "нуменорцы" → "нимеенцы" (от "Нуменор" → "Нимеен")
3. **Умная замена:** сначала длинные термины, потом короткие (избегает ложных срабатываний)
4. **Обработка ударений:** "Гло́ин" и "Глоин" → оба заменяются на "Гыен"
5. **Фэнтезийные имена:** похожи на оригинальные фонетически, но полностью вымышленные

## Технологии

- `requests` + `BeautifulSoup4` — веб-скрейпинг
- `faker` + custom generator — генерация фэнтезийных имён
- `re` + `unicodedata` — умная замена с учётом морфологии
