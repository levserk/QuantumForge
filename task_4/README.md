# Задание 4: RAG-бот с техниками промптинга

## Описание

RAG (Retrieval-Augmented Generation) бот, который:

- Ищет информацию в векторной базе знаний (71 документ о вымышленной вселенной)
- Использует Few-shot prompting (4 примера)
- Применяет Chain-of-Thought (размышления перед ответом)
- Работает через консольный REPL интерфейс

## Архитектура

```
Пользователь → console_bot.py → RAGBot → ChromaDB (поиск чанков)
                                           ↓
                                   OpenAI GPT-4o mini ← Промпт (Few-shot + CoT)
                                           ↓
                                   Ответ пользователю
```

## Файлы

- `rag_bot.py` - основной модуль RAG (класс RAGBot)
- `console_bot.py` - консольный интерфейс (REPL)
- `prompts.py` - промпты (System prompt + 4 Few-shot примера)
- `config.py` - конфигурация (пути, модели, параметры)
- `requirements.txt` - зависимости Python
- `.env.example` - шаблон для API ключа
- `.gitignore` - защита от коммита токена
- `examples.md` - примеры диалогов (5 успешных + 2 "не знаю")
- `README.md` - эта документация

## Технические детали

### Компоненты RAG

**Поиск (Retrieval):**

- База: ChromaDB из task_3 (353 чанка, 71 документ)
- Embedding: all-mpnet-base-v2 (768 dim)
- Top-k: 3 чанка
- Threshold: similarity > 0.4

**Генерация (Generation):**

- Модель: OpenAI GPT-4o mini
- Temperature: 0.3 (более предсказуемые ответы)
- Max tokens: 500

### Few-shot Prompting

4 примера в `prompts.py`:

1. Вопрос о персонаже (Глеб/Балин)
2. Вопрос о событии (битва гномов и орков)
3. Вопрос о месте (Архип)
4. Вопрос об артефакте (Семь Капитон)

Примеры извлечены из реальной базы знаний.

### Chain-of-Thought (CoT)

System prompt содержит инструкцию:

```
Сначала размышляй вслух, показывай свои шаги мышления.

Формат ответа:
Размышление: [твои шаги мышления]
Ответ: [итоговый ответ]
```

Это заставляет модель объяснять свою логику перед ответом.

### Обработка "не знаю"

Если все найденные чанки имеют similarity < 0.4, бот отвечает:

```
Размышление: Я просмотрел базу знаний, но не нашел достаточно
релевантной информации по этому вопросу.
Ответ: Я не знаю, эта информация отсутствует в базе знаний.
```

## Решение проблем

### Ошибка: "OPENAI_API_KEY не найден"

**Решение:** Создайте файл `.env` в `task_4/` со строкой:

```
OPENAI_API_KEY=your-actual-key
```

### Ошибка: "ChromaDB не найдена"

**Решение:** Сначала выполните задание 3:

```bash
cd task_3
python build_index.py
```

### Ошибка: "OpenAI API rate limit"

**Решение:**

- Проверьте, есть ли у вас кредиты на аккаунте OpenAI
- Добавьте платежный метод: https://platform.openai.com/account/billing

### Медленные ответы

**Причина:** Загрузка embedding модели при первом запуске (~420 MB)

**Решение:** Подождите 1-2 минуты при первом запуске. Далее будет быстро.

## Стоимость использования

**OpenAI GPT-4o mini:**

- Вход: $0.15 за 1M токенов
- Выход: $0.60 за 1M токенов

**Примерный расход на 1 запрос:**

- Промпт: ~800 токенов (system + few-shot + contexts + query)
- Ответ: ~150 токенов
- **Стоимость:** ~$0.0002 за запрос (0.02 цента)

**100 запросов = $0.02** (2 цента) 👍
